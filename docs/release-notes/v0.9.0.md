# v0.9.0 · A nicer simulation: the rich look

![The pasture in the new rich look after an inspection flight](https://raw.githubusercontent.com/CosminBMemetea/querra-fence/9693fc2/docs/media/result-overview.jpg)

The simulation gets a new default look: sky, a low afternoon sun, textured grass, hills, a farmyard and rounder
animals. The flight, the physics and the alert projection are unchanged.

**Models:** unchanged, **model-v0.3**. It was trained on the classic look and finds only 1 of 3 faults in the rich
one, so live detector tests use `--look classic`. model-v0.4 (v0.10.0) is trained on both looks.

## Highlights

- **New default look** (`sim/gen_world.py`):
  - a sky with clouds, a low and warm afternoon sun and a cool fill light;
  - textured grass from tileable albedo and normal maps made by `tools/make_textures.py`, with no downloaded assets;
  - rolling hills around the farm, with a valley for the road (`models/pasture_ground`, a mesh generated from
    `fence.json`). The paddock and the farmyard stay flat;
  - about 160 trees (broadleaf and fir) on the hills, small woods and a hedgerow along the road;
  - a farmyard: a barn with white trim and doors, a silo, hay bales and a farmhouse;
  - rounder cows (Holstein patches, ears, muzzle, udder, tail) and fleecy sheep.
- **`--look classic`** (or `GARDIAN_LOOK`, or `"look"` in `fence.json`) brings back the original world.
- **`tools/snap_world.sh`** renders still images from fixed viewpoints and prints the ground colour the inspection
  camera sees.
- **Media:** the README and project-page images were regenerated in the new look with `./start.sh demo`.

## Measured

| | |
|---|---|
| Flight time, camera rate | unchanged: 2:34, 14.6 fps |
| model-v0.3 live, classic look | 3 of 3 faults, 5 false alerts |
| model-v0.3 live, rich look | 1 of 3 faults, 0 false alerts |

## Install or run

```bash
./start.sh                   # the rich look
./start.sh --look classic    # the original world
```

## Known limits

- model-v0.3 barely sees faults in the rich look: a domain gap inside the simulation itself. Use `--look classic` for
  live detector tests, or model-v0.4 from v0.10.0.
- `tools/make_dataset.py` stays on the classic look in this release.
