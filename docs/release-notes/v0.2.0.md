# v0.2.0 · Ground station, Jetson brain, LD2450 radar

![LD2450 radar running on the Jetson](https://raw.githubusercontent.com/CosminBMemetea/querra-fence/v0.2.0/docs/media/ld2450-radar.png)

This release adds:
- a ground station that watches the pasture all the time;
- a Jetson that answers questions about what it sees;
- the first real sensor, an LD2450 mmWave radar, with a live web view and a Debian package.

**Models:** none yet. Detection is still simulated. The first fence detector, model-v0.1, came later the same day,
and the platform first used one in v0.3.0.

## Highlights

- **LD2450 radar on the Jetson.**
  - A live radar page for a HiLink LD2450 (24 GHz, up to 3 targets), read through a CH340 adapter.
  - Smooth targets and trails, a heatmap, distance and speed per target, a 60-second chart and an activity feed.
  - Open it from the Jetson's dock or from any device at `http://<jetson>:8077`.
- **Ground station and drone** (`./start.sh guard`). A simulated pole at the gate:
  - carries RGB, thermal and iToF sensors, plus a fence-voltage monitor;
  - sends the drone when an animal walks out or the wire goes dead;
  - serves its cameras as RTSP streams that a real Jetson can consume.
- **Jetson brain.** Type a question and hear the answer.
  - A local vision model (Ollama) looks at the camera frames and grounds its answers in live sensor facts.
  - It speaks with Piper.
  - It can replay a recorded run for demos.

## Install or run

Radar on a Jetson (JetPack 6):

```bash
sudo apt install ./ld2450-radar_1.0.1_all.deb
```

- It runs as a service from boot, and **LD2450 Radar** appears in the app menu.
- To change the serial port or the web port, edit `/etc/default/ld2450-radar`.
- Wiring: LD2450 TX → CH340 RXD, RX → TXD, 5V, GND.

Simulation:

```bash
git clone https://github.com/CosminBMemetea/querra-fence.git
cd querra-fence && ./start.sh guard
```

## Known limits

- Camera detection and fence voltage in the simulation are still simulated from Gazebo ground truth.
- The radar is not yet wired into guard mode as the gate counter. That is next on the roadmap.
- The vision-model path of the Jetson brain is not benchmarked on JetPack 6 yet. Without a model, the brain answers
  from sensor facts.
