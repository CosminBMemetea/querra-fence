**Gardian X500 v0.2.0** adds a ground station that watches the pasture all the time, a Jetson that answers questions about what it sees, and the first real sensor: an LD2450 mmWave radar with a live web view, installable as a Debian package.

![LD2450 radar running on the Jetson](https://raw.githubusercontent.com/CosminBMemetea/querra-fence/v0.2.0/docs/media/ld2450-radar.png)

### Highlights
- **LD2450 radar on the Jetson.**
  - A live radar page for a HiLink LD2450 (24 GHz, up to 3 targets) read through a CH340 adapter.
  - Smooth targets, trails, a heatmap, distance and speed for each target, a 60-second chart and an activity feed.
  - Open it from the Jetson's dock or from any device at `http://<jetson>:8077`.
- **Ground station + drone** (`./start.sh guard`). A simulated pole at the gate:
  - RGB, thermal and iToF sensors, plus a fence-voltage monitor;
  - it sends the drone when an animal walks out or the wire goes dead;
  - its cameras are RTSP streams a real Jetson can consume.
- **Jetson brain.** Type a question and hear the answer.
  - A local vision model (Ollama) looks at the camera frames, and its answers are grounded in live sensor facts.
  - It speaks with Piper.
  - It can replay a recorded run for demos.

### Install the radar on a Jetson (JetPack 6)
Download `ld2450-radar_1.0.1_all.deb` below, then:
```bash
sudo apt install ./ld2450-radar_1.0.1_all.deb
```
- It runs as a service from boot, and **LD2450 Radar** appears in the app menu.
- To change the serial port or web port, edit `/etc/default/ld2450-radar`.
- Wiring: LD2450 TX → CH340 RXD, RX → TXD, 5V, GND.

### Run the simulation
```bash
git clone https://github.com/CosminBMemetea/querra-fence.git
cd querra-fence && ./start.sh guard
```

### Known limits
- Camera detection and fence voltage in the simulation are still simulated from Gazebo ground truth.
- The radar is not yet wired into guard mode as the gate counter; that is next on the roadmap.
- The vision-model path of the Jetson brain is not benchmarked on JetPack 6 yet. Without a model, the brain answers from sensor facts.
